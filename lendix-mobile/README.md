# Lendix Mobile

Aplicación Flutter para Android conectada al backend de Lendix en Cloud Run.

## Credenciales de prueba

- Usuario: `admin`
- Contraseña: `Admin123@`

## Ejecutar localmente

```bash
flutter pub get
flutter run
```

## Generar APK

```bash
flutter build apk --release
```

El APK se genera en `build/app/outputs/flutter-apk/app-release.apk`.
